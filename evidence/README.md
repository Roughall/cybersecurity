# Evidence

Folder ini hanya untuk eviden assessment yang telah disanitasi dan disetujui.

Jangan simpan data pasien, identitas pribadi, kredensial, token, private key, cookie/session, dump database, konfigurasi rahasia, screenshot sensitif, atau log mentah yang mengandung rahasia.

Pola nama: `EV-<CONTROL-ID>-<NN>-<YYYYMMDD>-<description>.<ext>`

Sertakan metadata sesuai AGENT_HANDOFF.md. Jika eviden tidak aman untuk GitHub, simpan di penyimpanan institusi yang disetujui dan catat referensi internal tanpa menyalin konten sensitif.

Belum ada eviden assessment pada checkpoint awal.
